# Enigma Lab · Web Enigma Simulator

브라우저에서 작동하는 한국어 Enigma 학습 앱입니다. 키를 누르면 로터의 회전, 내부 배선의 전기신호 경로, 단계별 알파벳 변환과 출력 램프를 확인할 수 있습니다. 연산과 기록은 모두 현재 탭 안에서 처리합니다.

**웹에서 실행:** https://fishoutlaw.github.io/web-enigma-simulator/

## 바로 실행

**`dist/index.html`을 브라우저에서 여세요.** Windows에서는 저장소의 `start.cmd`를 더블 클릭해도 됩니다.

- 실행에는 Python, Flask, Node.js, 계정, 인터넷, 외부 CDN이 필요하지 않습니다.
- **`dist` 디렉터리만으로 작동합니다.** 파일 하나가 아니라 `dist` 전체를 복사하세요.
- 빌드된 배포본을 저장소에 포함하므로 처음 내려받은 사용자는 빌드할 필요가 없습니다.
- 기록은 탭 메모리에 보관하며 새로고침·탭 종료 시 삭제됩니다.

## 주요 기능

- 목재 프레임·금속 패널의 기계와 통합 키보드/램프, 실제 키보드 A~Z 입력
- I, II, III, IV, V 중 서로 다른 로터 3개 선택과 시작 위치 A~Z 설정
- 기본 I–II–III / AAA, 링 A 고정, 반사판 B, 플러그 최대 10쌍
- 일반 회전·회전 전달·더블 스테핑과 로터 전체가 한 칸 이동하는 시각화
- 로터·반사판 접점 1~26, 플러그 A~Z, 진입·복귀 방향을 구분한 SVG 배선도
- 배선도 100% 전체 보기와 130%·170% 확대
- 단계 이동·자동 재생·일시정지·속도 조절·문자별 기록 다시 보기
- 빠른 문장 처리와 암호문 복호화 비교
- 입력 대기열, 초기화 시 이전 작업 취소, 탭별 독립 실험

## 사용 방법

1. 화면 키를 누르거나 실제 영문 키보드로 입력합니다.
2. ‘로터 선택 · 시작 위치’에서 설정을 고르고 적용합니다. 이미 사용 중인 로터를 선택하면 해당 자리와 교환됩니다.
3. 플러그 문자 두 개를 선택해 연결합니다. 연결된 문자나 연결 목록의 ×로 해제합니다.
4. 중간 알파벳 또는 문자별 기록을 선택하면 해당 경로를 확인할 수 있습니다. 조회·재생은 계산 상태를 바꾸지 않습니다.
5. 문장을 입력하면 실제 처리할 문자열을 미리 보여줍니다. 소문자는 대문자로, A~Z 밖의 문자는 제외하며 제외된 문자는 로터를 회전시키지 않습니다.
6. ‘암호문으로 복호화 시연’을 누르면 시작 설정에서 복호화하고 원문과 비교합니다.

| 버튼 | 동작 |
|---|---|
| 시작 설정 복원 | 실험 시작 시의 설정으로 돌아가고 기록·대기열 제거 |
| 새 실험 | 현재 선택한 설정으로 기록·대기열을 비우고 시작 |
| 기본값으로 초기화 | I–II–III / AAA / 플러그 없음으로 초기화 |
| 현재 기계 보기 | 과거 기록 조회를 끝내고 현재 기계로 복귀 |

설정 적용과 플러그 변경은 새 실험을 시작합니다. 한 번의 문장 입력은 최대 500자입니다.

## 소스 수정·테스트

개발 도구는 **Node.js 20 이상**입니다. 외부 npm 패키지를 사용하지 않으므로 `npm install`은 필요하지 않습니다.

저장소 루트에서 실행하세요.

```sh
npm test
npm run build
npm run preview
```

미리보기 주소는 **http://127.0.0.1:5001**입니다. 미리보기 서버는 정적 파일만 전달하며 계산 API가 없습니다. 종료는 Ctrl+C입니다.

`src`를 수정한 뒤 `npm run build`로 `dist`를 갱신하세요. 빌드는 실행 파일과 배포용 README, 제3자 라이선스 고지를 함께 생성합니다. `dist`를 직접 수정하면 다음 빌드에 덮어씌워집니다.

배포본의 `enigma.js`는 DOM에 의존하지 않는 연산 엔진이며 회전·배선·신호 추적에 한글 주석이 포함되어 있습니다. `app.js`는 입력 대기열·기록·화면·애니메이션을 담당하고 `EnigmaEngine` API를 호출합니다. 두 파일은 `index.html`에 선언된 순서로 실행됩니다.
