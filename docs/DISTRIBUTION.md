# Enigma Lab · 실행용 배포본

이 폴더만 있으면 실행할 수 있습니다. **`index.html`을 브라우저에서 여세요.**
Python, Node.js, 설치, 계정, 인터넷 연결, 계산 서버가 필요하지 않습니다.

## 필요한 파일

이 폴더 전체를 함께 복사하거나 내려받으세요. `index.html` 하나만 복사하면 동작하지 않습니다.

```text
index.html
app.js
style.css
README.md
THIRD_PARTY_NOTICES.md
licenses/
  Py-Enigma-MIT.txt
```

## 사용

- 화면 원형 키 또는 실제 A~Z 키로 입력합니다. 로터 전체가 먼저 회전하고 전기신호 경로와 출력 램프가 표시됩니다.
- 로터 선택에서 I~V 중 서로 다른 3개와 시작 위치 A~Z를 고릅니다. 링은 A로 고정, 반사판은 B입니다.
- 플러그는 두 문자를 선택하여 연결합니다. 연결된 문자를 누르면 해제됩니다. 최대 10쌍입니다.
- 내부 숫자는 1~26이며, 플러그와 신호 입출력은 A~Z입니다. 배선도 100%는 전체 보기, 130%·170%는 확대 보기입니다.
- 단계별 알파벳이나 문자 기록을 선택하면 해당 경로를 다시 볼 수 있습니다. 재생·단계 이동은 로터를 추가 회전시키지 않습니다.
- 문장 입력은 영문만 처리하고 소문자는 대문자로 변환합니다. 빠른 문장 처리 후 ‘암호문으로 복호화 시연’으로 복원 결과를 비교하세요.
- 설정 변경·새 실험은 기록과 대기열을 비웁니다. 새로고침과 탭 종료 시 기록은 사라집니다.

## 출처

계산 코드는 [Py-Enigma](https://github.com/gremmie/enigma) 1.0.2를 참고하여 JavaScript로 재작성했습니다. 원본 MIT 고지는 `licenses/Py-Enigma-MIT.txt`에 있으며 배포 시 함께 유지하세요. 자세한 구분은 `THIRD_PARTY_NOTICES.md`를 참고하세요.
